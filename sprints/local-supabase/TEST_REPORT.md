اختبارات الأدوات تشمل رفض العناوين البعيدة، والمفاتيح السرية في ملف المتصفح، وحماية ملف بيئة قائم، ومنع تجاوز هدف التشغيل بمتغيرات البيئة، ومنافذ loopback، والتأكيد الإلزامي لحذف بيانات التدريب، وحجب الأسرار من التشخيص. كما اختُبر تجهيز دليل التدريب مرتين على PGlite دون مضاعفة البيانات أو اختلاق مخزون أو فواتير، وصلاحيات قراءة التقارير بعد التجهيز.

اختبارات استرجاع مستخدم Auth بعد نتيجة إنشاء غير محسومة تستخدم **موصلات وهمية للاختبار**؛ لا تُعد اختبارًا لخادم Auth. واختبارات انقطاع الإنترنت في الواجهة تستخدم حالة متصفح محاكاة؛ لا تُعد تجربة فصل شبكة فعلية.

- `npm run local:smoke`: 25 تحققًا مجهزًا على Auth وPostgREST الفعليين عبر ستة حسابات. لم يُشغّل ولم تنشأ أي كلمات مرور تدريب هنا.
- `npm run local:test-db`: 54 حالة قاعدة بيانات و8 حالات تزامن على خادم PostgreSQL 16 مستقل. لم يُشغّل بسبب غياب Docker، ولا يُستخدم نجاح PGlite بديلًا عنه.
- Windows/Android الفعليان، والطباعة الورقية، وفصل الإنترنت الحقيقي وإعادة تشغيل الجهاز، والنسخ الاحتياطي والاستعادة.
- النشر السحابي والربط مع Oracle/OpenAI/WhatsApp/Drive خارج هذه الحزمة ولم تُجرّب.

فحوص GitHub السابقة كانت محجوبة بسبب فوترة الحساب. نتائج هذا التقرير محلية؛ لا توجد مطالبة بنجاح GitHub CI أو جاهزية النظام الإنتاجية الكاملة.

## تصحيحات عن الدليل المقترح

- استُخدمت ملفات الترحيل الخمسة القائمة، دون تجميعها في ملف init جديد أو تطبيق هجرات الجذر التاريخية.
- الاتصال بمتغيرات Next العامة ومفتاح publishable فقط؛ لم يُلصق مفتاح داخل `src/supabaseClient.ts` أو أي كود متصفح.
- `local:dev` يفرض إعداد العملية المحلية دون استبدال ملف إعداد سحابي قائم.
- لا reset عند التشغيل؛ له أمر منفصل يتطلب تأكيدًا صريحًا ويستهدف المشروع المحلي فقط.
- الشيفرة المحلية لم تعد تمنع إرسال طلب إلى localhost لمجرد أن المتصفح لا يرى الإنترنت. فشل RPC الحقيقي يظل فشلًا ويحفظ مرجع منع التكرار.
- Studio الإداري ليس إثباتًا لسياسات RLS. لهذا أضيف اختبار JWT/أدوار منفصل عبر واجهة الخدمة.
