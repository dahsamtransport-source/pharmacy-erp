# تقرير اختبار Sprint 1

التاريخ: 2026-09-20. بيانات الاختبار مصطنعة؛ لا بيانات مرضى أو معاملات إنتاجية.

- نجحت **34 حالة** على PGlite 0.5.8 باستخدام SQL فعلي وNode.js 24.
- شملت: توازن القيد وتكلفة البضاعة، المتوسط المرجح، تحويل العبوات، FEFO، استبعاد المنتهي والمحجور، الاسترجاع الكامل بعد الفشل، منع تكرار الفواتير، الحجز والإلغاء والانتهاء والإتمام، RLS وعزل المنشآت، منع تسرب تكلفة المشتريات حتى بعد تغيير الدور، منع انتحال الصلاحية، الفترة المقفلة، حماية سجل التدقيق، شجرة الحسابات، مراجعة الوصفة، سقف التأمين والموافقات والاستثناءات والتقارير.
- كُتبت **8 حالات تزامن** لاتصالين مستقلين على PostgreSQL 16. لم تبدأ مهمة GitHub Actions لأن الحساب موقوف بسبب مشكلة فوترة، بحسب التعليق الصريح في [تشغيل CI رقم 35481232561](https://github.com/dahsamtransport-source/pharmacy-erp/actions/runs/35481232561). لذلك الحالات الثماني **غير منفذة**؛ لا تُحتسب PGlite دليلاً على التزامن الحقيقي.
- أعاد `npm audit` لحزمة الاختبار المعزولة صفر ثغرات معروفة، ونجح فحص صياغة ملفات الاختبارات و`git diff --check`. هذا لا يشمل اعتمادًا أمنيًا للتطبيق القديم.
- أمر `test:postgres` يرفض العمل عند غياب إعداد PostgreSQL الفعلي؛ لا يعطي نجاحًا كاذبًا بالرجوع إلى PGlite.
- لم تُطبّق الهجرات على Supabase أو Cloudflare أو Modern Soft. لم يُختبر Supabase Auth/PostgREST الفعلي، ولا أداء حجم إنتاجي، ولا استعادة نسخة تشغيلية، ولا واجهة وأجهزة فعلية.
- لا توجد تغييرات React/TypeScript في Sprint 1؛ لم يُدَّع نجاح بناء واجهة جديدة أو اختبار الطباعة وOCR.

## إعادة التشغيل

التعليمات الدقيقة في README.md. ملفات الاختبارات تنشئ auth.uid() بديلًا داخل قاعدة اختبار محلية فقط. اختبارات PostgreSQL الخادمية تحمي نفسها بشرط اسم قاعدة ثابت وعنوان localhost وموافقة بيئة `YMPHARMA_DISPOSABLE_TEST_DB=yes`؛ هي مدمرة لمخططات ym* الخاصة بالاختبار.

## حدود الأمان

حماية التطبيق مثبتة بالاختبارات المذكورة، وليست ضمانًا بعدم الاختراق. يلزم قبل الإنتاج: مراجعة مستقلة، تهيئة Auth وMFA وأسرار الخادم، اختبار API كامل، تحديد سياسة النسخ والاستعادة والاحتفاظ، قياس الأداء، وخطة النقل والمطابقة. توجد اختبارات مُعدة للقفل المتزامن، لكن لا يُعلَن اجتيازها حتى تعمل على PostgreSQL خادمي.

الحزمة محفوظة في [مسودة المراجعة #5](https://github.com/dahsamtransport-source/pharmacy-erp/pull/5). المطلوب لإتمام بوابة الاختبار الخادمي: معالجة مشكلة فوترة GitHub وتشغيل المهمة، أو تشغيل الأوامر الموثقة على PostgreSQL محلي مخصص للاختبارات. لا يلزم إرسال أي سر في المحادثة.
