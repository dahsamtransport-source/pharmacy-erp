## ما تثبته الحالات الجديدة

- شراء وصرف فعليان داخل محرك SQL ينتجان دخلًا وتكلفة ومجاميع تقرير صحيحة.
- الأرصدة قبل الفترة تبقى افتتاحية؛ أول يوم وآخر يوم داخل الفترة، واليوم التالي خارجها.
- عدد القيود، والأرصدة والدخل تُصفّى جميعها بمركز التكلفة نفسه.
- قاعدة بلا قيود لا تعني دفاتر مكتملة؛ عرض الحسابات الصفرية لا يغيّر المجاميع.
- المستخدم غير المالي، والعضوية الملغاة، والمنشأة الأخرى، والمركز الأجنبي، والدور المجهول لا يحصلون على التقرير.
- القيود غير المرحّلة لا تدخل التقرير، والأرصدة التاريخية للحساب المعطل تبقى ظاهرة.
- الأرقام الكبيرة مثل `90071992547409.41` تحتفظ بدقتها العشرية؛ الإشارات العكسية للإيراد والتكلفة لا تنقلب خطأ.
- العملات المختلطة وربط تكلفة المبيعات الناقص أو المصنف خطأ يوقفان التقرير.
- الاستجابات ذات المجاميع الفاسدة أو الصفوف المكررة أو المنطقة الزمنية الخاطئة تُرفض قبل العرض.
- طبقة API تتحقق من المنشأة والفترة ومركز التكلفة وتخفي التشخيص الداخلي عن المستخدم.
- تاريخ البداية يتبع منطقة المنشأة حول حد الشهر، ولا يُشتق خطأ من UTC.
- تبويب الدخل يعرض تكلفة المبيعات مستقلة؛ تبديل التبويب لا يكرر الاستدعاء بلا سبب.
- عوامل تصفية معدلة تمنع الطباعة إلى أن تُطبّق؛ بعد التحديث تطابق الترويسة البيانات الجديدة.
- تحديث الفترة نفسها يجلب البيانات مجددًا. الانقطاع يمنع تحديثًا جديدًا، والخطأ يمنع طباعة تقرير غير موجود.
- CSV يحفظ العربية والدقة والإشارات ويحيّد نصوص الصيغ؛ هذا اختبار المحتوى، وليس اختبار فتحه في كل برنامج جداول.

## محاولة إكمال اختبار التزامن

بسبب تعطل GitHub Actions السابق بفوترة الحساب، جرى تجهيز حزمة `embedded-postgres@16.14.0-beta.17` خارج المستودع لتشغيل PostgreSQL محلي معزول. لم يبدأ خادم الاختبار: البيئة تعرض UID 0 فقط ولا تسمح بالانتقال إلى مستخدم النظام غير الجذري الذي يشترطه PostgreSQL. النتيجة كانت `runuser: cannot set groups: Operation not permitted`، وفشلت محاولة ملكية مجلد الاختبار بـ`Invalid argument`.

لم يتم تجاوز هذا القيد أو تعديل حسابات النظام. اختبارات C1–C8 ذات الاتصالين تبقى **غير منفذة**. ملفاتها وCI موجودة، ويمكن تشغيلها على PostgreSQL 16 مستقل باستخدام تعليمات Sprint 1 بعد توفر بيئة مناسبة. نجاح PGlite ليس دليلًا على التزامن بين اتصالات مستقلة.

## ما لا تثبته هذه النتائج

- لا تثبت سلامة ترحيل البيانات القديمة أو جاهزية قاعدة الإنتاج؛ الهجرة ما زالت ضمن مسار التقييم.
- لا تثبت مظهر A4 أو محاذاة العربية على الطابعة أو أداء الهاتف؛ اختبار `window.print()` وتنسيقات CSS ليسا اختبار طابعة فعلية.
- لا تثبت سرعة التقارير على حجم إنتاجي أو تحديثًا لحظيًا بالدفع.
- لا تثبت اعتمادًا ضريبيًا أو محاسبيًا أو طبيًا. التوازن الحسابي أحد الشروط فقط.
- موقع Oracle الحالي وقواعده وموصلاته لم تُعدّل أو تُنشر ضمن هذا التغيير.

الحالة: وظائف التقارير مبنية ومختبرة محليًا، وجاهزة لمراجعة الكود وربط بيئة اختبار قبل القبول الإنتاجي.
