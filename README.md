# موصل — Mawsil Transaction Core

واجهة عربية تجريبية ونواة معاملات مبنية على Next.js وPostgreSQL/Supabase.
هذا الفرع غير معتمد للإنتاج، والذكاء الاصطناعي لا ينفّذ أي عملية مالية.
الاسم التاريخي للمستودع هو Pharmacy ERP.

## التشغيل والتحقق المحلي

```sh
npm ci
npm run typecheck
npm run lint
npm test
npm run test:db
npm run build
npm run dev
```

`test:db` يعيد بناء المخطط في PGlite مع فحوص عزل التجار والصلاحيات
والموافقات وعدم تكرار الأثر المالي والتراجع عند الفشل. لا يثبت التزامن
متعدد الجلسات أو الاتصال الفعلي بـSupabase.

لاختبار PostgreSQL مستقل، شغّل `npm run test:db:postgres` بعد ضبط
`MAWSIL_TEST_DATABASE_URL` على خادم اختبار محلي مخصص وقاعدة `/postgres`.
ينشئ الاختبار قاعدة مؤقتة باسم عشوائي ثم يحذف هذه القاعدة وحدها.
لا تستخدم بيانات إنتاج أو توجيه اتصال إلى خادم إنتاج. أُضيف هذا الفحص إلى CI.

## الإعداد والحدود

استخدم المتغيرات الموضحة في `.env.example` داخل إعدادات الخادم فقط.
لا تضع مفاتيح الخدمة أو مفاتيح OpenAI في المتصفح أو Git.
يبقى `MAWSIL_AI_PLANNING_ENABLED=false` حتى التحقق من تسجيل الدخول
وحدود الطلبات والإنفاق. زر الواجهة يقترح القسم محليًا فقط ولا يستدعي النموذج.

- عمليات قاعدة البيانات تُنفّذ عبر RPC محمي، وليس بالكتابة المباشرة إلى الجداول المالية.
- يمنع الفرع خلط العملات في رصيد واحد؛ لم يُنجز دفتر مستقل لكل عملة بعد.
- إلغاء الفواتير المسدّدة محظور حتى اكتمال توزيع الدفعات والاستردادات.
- لا توجد بعد واجهة تشغيل مالية كاملة أو دورة مزامنة Offline معتمدة.
- Next.js الحالي يحتاج تهيئة استضافة متوافقة قبل نشره على Sites؛ لم يُنشر تلقائيًا.
