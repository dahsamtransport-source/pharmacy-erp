# Provenance

Official source: https://github.com/Graphify-Labs/graphify
Official package: `graphifyy` (double y); command: `graphify`.
Pinned and tested integration version: 0.9.108, 2026-11-14.
The helper and instructions here are an independent integration, using the
official package without vendoring or modifying its source.

The `sql` extra parses schema files locally. This integration does not use
`--postgres`, cloud sync, model backends, or semantic document extraction.
Supported commands are verified against the pinned CLI help. Consult current
upstream documentation and test before upgrading the version.
